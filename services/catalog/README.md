# Catalog

Сервис публикаций и групп вариаций. PostgreSQL хранит метаданные медиа,
членство в группах и голоса. Оригиналы и результаты обработки находятся в S3.

Публикация создается сразу после проверки загруженного файла.
Точный дубликат SHA-256 отклоняется со ссылкой на существующее медиа.
Изменения группы и подсчет голосов выполняются в транзакциях.

API создает загрузки, возвращает ленту и медиа, удаляет собственные публикации,
принимает голоса за объединение и открепление вариаций. Схемы доступны в /docs.

Настройки PostgreSQL, S3, соседних REST API и ограничений задаются окружением
с префиксом MEMES_. Полный состав указан в deploy/compose.yaml.
Из корня репозитория после настройки окружения:

```sh
poetry run memes-catalog
```

Тесты и фикстуры находятся в tests/. Из этой директории:

```sh
poetry install --with test
poetry run pytest -p no:cacheprovider
```

Интеграционные проверки требуют MEMES_CATALOG_TEST_DATABASE_URL
и параметров MEMES_CATALOG_TEST_S3_*.
