# Processing

REST-координатор обработки медиа. PostgreSQL хранит источники, задачи,
попытки выполнения, lease и очередь доставки результатов.

API регистрирует доверенные устройства и выдает им задания через исходящие
запросы воркера. Результат принимается только от назначенного устройства
для актуальной попытки и согласованной версии модели. Неудачные задания
повторяются с ограничением попыток и экспоненциальной задержкой.

Настройки задаются окружением с префиксом MEMES_: DATABASE_URL,
INTERNAL_API_KEY, RELEASE_ID, HOST, PORT, адреса Identity/Catalog/Search
и параметры S3. Схемы запросов доступны в /docs.

Из корня репозитория после настройки окружения:

```sh
poetry run memes-processing
poetry run memes-processing-coordinator
```

API и координатор запускаются отдельными процессами.
Миграции выполняются до запуска API.

Тесты и фикстуры находятся в tests/. Из этой директории:

```sh
poetry install --with test
poetry run pytest -p no:cacheprovider
```

Интеграционные проверки требуют MEMES_PROCESSING_TEST_DATABASE_URL.
