# Memes Kernel

Минимальные общие примитивы: идентичность сущности, ревизия, хэш, ссылка
на содержимое файла, проверки времени и доменные ошибки.
Пакет не зависит от фреймворков и не содержит сущностей других сервисов.

## Локальные тесты

Тесты и фикстуры находятся в `tests`. Из директории компонента:

```shell
poetry install --with test
poetry run pytest -p no:cacheprovider
```

Проверки Ruff и mypy запускаются из корня репозитория.
